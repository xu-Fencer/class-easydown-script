# class-easydown

西安交通大学在线学习平台 (class.xjtu.edu.cn) 课程回放批量下载工具 — Tampermonkey 用户脚本版。

## 功能

- 在「录播教材」页面每行视频旁注入两个按钮：**老师路**（教师画面，静音）和**电脑路**（课件画面，有声）
- 点击「获取 xx 路链接」→ 异步解析真实下载地址 → 按钮变为「⬇ 下载 xx 路视频」
- 「⚡ 一键获取全部链接」按钮：一次点击，并发获取页面上所有视频的两路下载链接
- 点击下载按钮触发浏览器原生下载
- 支持多页课程（翻页自动注入）
- 底部保留旧版批量面板（可折叠）

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 打开 Tampermonkey → 新建脚本
3. 将 `class-easydown.user.js` 全部内容粘贴进去 → 保存
4. 访问课程「录播教材」页面（如 `https://class.xjtu.edu.cn/course/120682/lesson#/`）

## 使用

```
进入课程「录播教材」页面
  ├── 每行视频出现 [👨‍🏫 获取老师路] [🖥️ 获取电脑路]
  ├── 点击按钮 → 加载动画 → 变为 [⬇ 下载xx路视频]
  ├── 再点一次 → 浏览器开始下载
  └── 顶部「⚡ 一键获取全部链接」一次获取本页所有链接
```

## 前置条件

- 浏览器已登录 class.xjtu.edu.cn
- Tampermonkey 扩展已启用
- 脚本的 `@connect` 域名已在 Tampermonkey 中授权（首次运行会弹窗确认）
